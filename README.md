# Название проекта

Простая реализация утилит ОС Linux cat/grep на языке C.

## Расположение проекта

- Исходные файлы: `/src`
- Ветка разработки: `develop`

## Реализованные команды и флаги

### Команда `cat` с поддержкой флагов:

| Флаг (GNU аналог)       | Описание |
|-------------------------|----------|
| `-b` (`--number-nonblank`)| Нумерует только непустые строки |
| `-e` (GNU: `-E`)         | Показывает символы конца строки как `$` (подразумевает `-v`) |
| `-n` (`--number`)        | Нумерует все строки вывода |
| `-s` (`--squeeze-blank`) | Сжимает несколько пустых строк подряд |
| `-t` (GNU: `-T`)         | Показывает табы как `^I` (подразумевает `-v`) |

### Команда `grep` с поддержкой флагов:

| Флаг | Описание |
|------|----------|
| `-e` | Шаблон для поиска |
| `-i` | Игнорировать регистр |
| `-v` | Инвертировать совпадения |
| `-c` | Выводить только количество совпадающих строк |
| `-l` | Выводить только имена файлов с совпадениями |
| `-n` | Добавлять номер строки перед совпадением |
| `-h` | Не выводить имена файлов перед совпадениями |
| `-s` | Подавлять сообщения об ошибках |
| `-f` | Брать регулярные выражения из файла |
| `-o` | Выводить только совпадающие части строк |

### Установка
Компилляция проекта проводится с помощью утилиты make из консоли.

make all - сборка проекта.
make test - интеграционные тесты, выполняются путем сравнения результатов работы
оригинальной утилиты cat/grep и моей реализации.
